# 这份报告的判据已被修订，不要直接引用它的分数

跑完 run1 之后发现两条断言是从旧架构直译过来的，翻译得不对：

1. `departure_date` 只统计**成功执行**的搜索。H-03c 里模型把日期读对了
   （`arrive_by=2026-08-05`），是工具按"不许搜已过去的日期"把这次调用拒了。
   把这两件事记成同一个失败，会把模型的日期能力分数记错。
   → run2 拆成 `departure_date_read_correctly` 和 `departure_date_searched`。

2. `cities_preserved` 在工具循环里当场不可观测：还没搜之前，城市只存在于对话里，
   没有任何字段承载它。H-04 因此挂在一个架构上不存在的观测点上。
   → run2 换成真的追问一轮，再看它搜的是哪两个城市。

修订后的结果见 `../toolloop-cal-20260829-run2/`。run1 保留是为了留住"判据改过"
这件事本身的证据，按 AGENTS.md 不覆盖历史评测目录。
